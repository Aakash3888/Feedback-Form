# 📝 KANAK DOVLOPER — Feedback Form

A professional, modern, and interactive **3-step feedback form** built with pure **HTML, CSS, and JavaScript** for **KANAK DOVLOPER**.

---

## 📁 Files

| File | Purpose |
|------|---------|
| `index.html` | Form structure & markup |
| `feedback.css` | Modern styling with animations |
| `feedback.js` | Interactions, validation & submission |

---

## ✨ Features

### 📊 3-Step Form
- **Step 1** — Satisfaction rating (emoji + stars)
- **Step 2** — Feedback type selection
- **Step 3** — Personal details & message

### 🥰 Emoji Rating
- 😠 Terrible → 🤩 Excellent (5 levels)
- Animated pop effect on selection
- Color-coded labels

### ⭐ Star Rating
- 1–5 star interactive rating
- Hover preview effect
- Dynamic rating text ("Terrible" → "Excellent!")

### 📂 6 Feedback Types
| Type | Icon |
|------|------|
| Service Quality | 🎧 |
| Product Quality | 📦 |
| Delivery & Shipping | 🚚 |
| Customer Support | 👥 |
| Website / App | 🌐 |
| Other | ⋯ |

### 📝 User Details
- Name (required)
- Email (required, validated)
- Phone number (optional)
- Detailed feedback message (required)
- Recommend: Yes / Maybe / No

### ✅ Validation & Feedback
- Error toast notifications
- Shake animation on invalid step
- Email format validation
- Required field checks

### 🎉 Success Screen
- Animated checkmark
- Thank-you message
- "Submit Another Feedback" reset button

### 🎨 Design Highlights
- Pink → Orange brand gradient
- Floating animated orbs background
- Grid pattern decoration
- Shimmer progress bar
- Smooth transitions & hover effects
- Fully responsive (mobile-first)

### 📱 Extras
- Haptic vibration feedback on mobile
- Loading spinner on submit
- Auto-scroll on step change

## 🚀 How to Run

### Option 1 — Direct
```bash
open "FEED BACK/index.html"
```
Double-click **`index.html`** — it opens in your browser.

### Option 2 — VS Code Live Server
```bash
1. Install "Live Server" extension in VS Code
2. Right-click index.html
3. Select "Open with Live Server"
```
